📚 Guía de Estudio

Plan de 1 Mes: De Cero a Programador

Semana 1 (Días 1-7)Fundamentos
🔌

Electrónica Básica y Hardware

Voltaje (presión), Corriente (flujo), Resistencia (tubo). Ley de Ohm (V=I*R). Componentes como LEDs, resistencias y la Protoboard. Los pines del Arduino (números) y estados HIGH/LOW.

📦

Variables y Operadores

Cajitas para guardar datos: int (enteros), float (decimales), String (textos). Operadores matemáticos (+, -, *, /) y lógicos (&&, ||).

Semana 2 (Días 8-14)Control de Flujo
🤔

Decisiones (if / else / switch)

Si pasa esto, haz aquello. Los operadores mayor (>), menor (<), igual (==). El switch para menús de opciones múltiples.

🔄

Bucles y Funciones

El bucle `for` (repite X veces) y `while` (repite mientras pase algo). Crear funciones propias con `void` (no devuelve) o `int` (devuelve un número).

💬

Comunicación Serial

Hablar con la PC. `Serial.begin(9600)`, `Serial.print()`. Es la base para entender cómo funciona el Bluetooth.

Semana 3 (Días 15-21)El Mundo Físico
⚙️

Actuadores: Motores y Servos

`digitalWrite` para dirección, `analogWrite` (PWM 0-255) para velocidad. Servomotores (0-180 grados) con `Servo.h` y `attach()`.

👁️

Sensores y Pantallas

Ultrasónico (pulseIn / 58.00). Sensores Agroindustriales (Humedad analógica A0, DHT11). Pantalla OLED (U8g2, I2C A4/A5) para mostrar datos.

Semana 4 (Días 22-30)Integración y Proyecto
📡

Bluetooth y ESP32

Control remoto con `Serial.read()` y `switch`. ESP32 (3.3V, ADC 12 bits, WiFi, ledcWrite).

🏆

El Examen Final: 600 Líneas

La trampa del `while(Funtion_Flag)`. El código original atrapa el loop. Debes meter tu código de sensores DENTRO del while para que funcione.
